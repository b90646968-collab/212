# AI Runway Codex Harness

This repository is a private workspace for AI content creation and Codex-centered agent harnessing.

It combines:

- an AI runway character portfolio kit
- reusable image and video generation prompts
- Codex workspace instructions in `AGENTS.md`
- repo-scoped Codex skills in `.agents/skills/`
- a project-oriented think tank in `think-tank/`

## Project Title

AURELIA NOIR: AI Runway Character Film

## Concept

Pinterest fashion references and K-pop-inspired beauty aesthetics are reinterpreted into an original AI-generated luxury runway character.
The project explores fictional branding, character design, couture styling, and cinematic AI video direction.

Important: Do not copy a real celebrity, real person, existing character, or real brand logo. Use references only for mood, silhouette, styling, lighting, and direction.

## Codex Harness

This workspace is intentionally small:

- `AGENTS.md` holds durable operating rules for Codex in this workspace.
- `.agents/skills/` holds repo-scoped skills Codex can discover from this folder.
- `think-tank/` stores reusable preferences, ideas, prompts, and decisions.
- `docs/` explains the harness structure and the next decisions to make.

## Current Focus

## Workflow

1. Collect visual references.
2. Generate an original fictional character.
3. Build a fictional luxury brand.
4. Lock the outfit and character identity.
5. Generate runway key visuals.
6. Convert key visuals into an AI video.
7. Edit into a short brand film.
8. Save reusable decisions and repeated prompt patterns into the think tank after permission.

## First Rule

Keep the harness useful before it becomes elaborate. Add new rules only when they prevent repeated explanation or repeated mistakes.
