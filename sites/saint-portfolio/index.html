WORK PROCESS

아이디어를 결과물로 만드는 과정

작업을 시작하기 전에 기준을 만들고, 초안이 나온 뒤에는 선택과 보정을 거쳐 팀이 검토하기 쉬운 형태로 정리합니다.

01

Plan

목표, 타깃, 매체, 컷 목적과 반드시 보여야 할 요소를 한 장으로 정리합니다.

02

Reference

인물 얼굴, 제품 비율, 색상, 소재, 조명을 흔들리지 않는 기준으로 먼저 잡습니다.

03

Shot

카메라, 동작, 배경, 시작과 도착 프레임을 나눠 컷 구성과 스토리보드를 설계합니다.

04

Edit

아쉬운 컷을 덜어내고 형태 오류, 색감, 텍스트, 크롭을 보정해 사용할 장면만 남깁니다.

05

Share

영상 편집과 사운드, 제작 노트, 이미지 파일을 정리하고 웹 페이지와 공유 링크로 완성합니다.

CONTROL POINTS 제품·인물의 일관성, 컷의 목적, 최종 사용처를 끝까지 확인합니다.
WEB READY 파일 구조, 웹 구현, 자산 검수, 반복 수정과 배포까지 하나의 작업 흐름으로 연결합니다.
