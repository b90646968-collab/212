PROJECT NOTES

프로젝트별 적용 지점

01 / AEROFLEX브랜드 콘셉트 → 스포츠 동작 → 모션 테스트 → 최종 영상

정장과 스포츠의 대비를 고정하고 서로 다른 공간과 동작을 하나의 퍼포먼스웨어 서사로 연결했습니다.

 02 / LUMORA브랜드 팔레트 → 제품 오브제 → 가상 공간 → 3D 영상

향수 보틀의 곡선과 골드 디테일을 건축과 오브제 언어로 확장해 하나의 브랜드 공간으로 연결했습니다.

 03 / MUSINSA대표 이미지 → 세대별 룩 → 스토리보드 → 프레임 제어

오렌지·블랙 기준을 고정하고 서로 다른 인물과 장면을 하나의 흐름으로 연결했습니다.

 04 / SAINT얼굴 기준 → 의상 규칙 → 장면 일관성 → 보정

캐릭터 기준표를 중심으로 장면이 바뀌어도 같은 인물로 읽히도록 검수했습니다.

 05 / LE FAIRY제품 비율 → 향별 무드 → 6초 모션 → 제출 페이지

퍼퓸밤의 형태를 유지하면서 빛, 꽃과 기포의 움직임으로 향의 차이를 표현했습니다.
