# Texture Prompt Index

## Workflow

1. Read `prompts/README.md` first to find the texture source file.
2. Use `prompts/test-h01_texture.md` as the texture vocabulary base.
3. Keep texture requests texture-only unless the user asks for mood, scene, or style.
4. Combine the texture base with subject, composition, and edit goals only after the texture target is chosen.
5. When comparing variants, preserve the same subject framing and change only the texture terms.

## Use Cases

- build a new portrait prompt from a texture reference
- strip mood words out of a prompt and keep only surface detail
- pull a reusable texture phrase for future image edits
