# Red Frame Trigger Storyboard

## Purpose

Use this storyboard as the source of truth before creating or editing image, video, or opening-cut prompts for Red Frame Trigger.

Prompts should be generated from a storyboard beat first, not from isolated visual ideas. If a requested cut does not fit an existing beat, add or revise the storyboard beat before writing the final tool prompt.

## Character Profile Sources

- Yura: use `profiles/yura.md` as the canonical profile for all Yura cuts.
- Yuri: use `profiles/yuri.md` as the canonical profile for all Yuri cuts.

## Operating Rules

- Keep the prompt bank focused on Yura and Yuri only.
- Store broad world details, symbols, props, and environment ideas as storyboard beats unless the user asks for a dedicated prompt.
- Preserve Yura and Yuri continuity from `think-tank/projects/red-frame-trigger.md`.
- Prefer emotional opening plates over action shots.
- Default format is 16:9 unless the user asks otherwise.
- Every generated image prompt should include the final prompt used.
- Yuri and Yura must share the same color palette and painterly texture. Do not drift Yuri into a separate visual style.

## Prompt Assembly Order

1. Choose or revise the storyboard beat.
2. Load the relevant character profile.
3. Choose the canonical look or pose reference.
4. Add Red Frame Trigger style and continuity constraints.
5. Add tool-specific requirements only at the end.

## Core Arc

1. Yuri disappears and leaves only traces: red memory marks, mirror fragments, film-like clues, smoke, and empty rooms.
2. Yura remembers their childhood closeness and the moment of separation.
3. Yura chases Yuri's traces through absence, water, corridors, rooftops, dream rooms, and distorted reflections.
4. Yuri appears as a missing memory, mirror image, unreachable twin, or preserved earlier self.
5. Yura wakes from the nightmare with the search unresolved.
